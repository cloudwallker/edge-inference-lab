# 研究决策记录

记录日期：2026-09-29。以下记录范围、证据和待验证事项，不证明新颖性或任何人的个人理解程度。D01–D07保留设计时的判断，D08记录实施后的证据与修正；详细数字以[发现](findings.md)和原始结果为准。

## D01：采用 CPU 参数化模拟

**问题。** 首期怎样建立小而可复查的研究流程？

**解释 / 决策。** 使用合成请求、论文参数及事件账本，先实现公式指导的学习重实现；不训练视觉模型，也不部署真实 LLM 服务。

**证据。** [主论文](https://www.cs.cityu.edu.hk/~weliang/papers/ZLXJY25.pdf) §VI-A、Tables II/III 使用网络与服务参数仿真。[第二篇](https://www.cs.cityu.edu.hk/~weliang/papers/ALL26.pdf) 提供相邻资源竞争方向，但其 LSTM/MAB/重训机制超出首期范围。

**疑问。** 小规模实际耗时、内存及算法偏差如何？未测量前不能保证性能。

**实现影响 / 下一验证。** 从手工例开始，分开记录程序运行时间与模拟服务延迟；产物定位为学习模拟器，禁止把标称精度写成真实测量质量。

## D02：保留 Algorithm 2 的公式路径，公开解释歧义

**问题。** 原式与伪代码不一致时怎样避免静默补齐？

**解释 / 决策。** 按 Eq. (31)/(32) 独立生成 new/existing；联合 typed-mode argmax，按获胜 mode 只更新对应对偶；每 slot 冻结 Cᵗ/nᵗ。不使用贪心替代，不继承竞争比。

**证据。** 主论文页 6217–6219，Eq. (39)–(42)、Algorithm 2、Lemma 6、Theorem 2；候选 AND、mode 丢失和 L 因子问题列于 [主论文笔记](reading/01-main-paper.md)。

**疑问。** 原作者怎样处理交集候选、No_pre 零分母、No_control 及全时域界？尚缺无歧义实现依据。

**实现影响 / 下一验证。** 手算候选、得分、mode、更新和利润；事先从配置推导界，禁止测试轨迹回填。解释变体另行命名，不把所有对照标成作者精确基线。

## D03：区分常驻 floor、额外实例和物理分组

**问题。** 非零底座、实例容量和 θ 淘汰如何放在同一账本？

**解释 / 决策。** 采用每节点/模型/分辨率一份常驻 floor；θ 管理额外实例。new 分配按类型组成 `ceil(count / L)` 个物理实例；固定具体实例槽位和计数映射。

**证据。** 主论文 §V-A–B、§VI-A、Eq. (21)；Table III 推导底座为三模型 × `(0.5+0.5+1+1)` = **9 模拟 vCPU/节点**。逐节点常驻是项目解释，不是原文明确指定。

**疑问。** 原文底座是常驻还是淘汰后补回？若只有底座被使用，保留策略是否没有机会产生差异？

**实现影响 / 下一验证。** 所有 θ 对照共享 floor、初态和容量；检查额外创建、闲置、再访及释放时点。分别记录逻辑槽位与 ceil 后物理容量违反；严格 hard-cap 版本不能沿用原式结论。

## D04：把定价与单位不确定性作为显式假设

**问题。** 缺失收费表和 ξ 单位冲突会怎样影响利润？

**解释 / 决策。** 采用公开的人为 ψ 阶梯表及统一上传时间单位，所有策略共享；原式没有独立创建货币费或闲置费。

**证据。** 主论文 §III-C Eq. (2)–(4) 与 §VI-A；完整价格边界/金额未给出，ξ 的两处单位表述不一致。

**疑问。** 定价的另一种合理解释是否改变策略排名？不能称当前配置精确复现作者利润。

**实现影响 / 下一验证。** 检验单位和费用分项；保留价格敏感性为后续项。任何扩展费用另列目标，禁止混入原论文利润。

## D05：保留可证伪配对假设，放弃宽泛创新声明

**问题。** 在到达、模型及精度/期限各自边际相同的情况下，仅改变配对关系，保留策略表现是否改变？

**解释 / 假设 H1。** 同一访问频率未必意味着各分辨率实例同等有用；精度与期限的配对可能改变暖实例的可行性和服务价值。因此仅按访问间隔留存，可能不足以表达这种差异。H1 可能被否定。

**证据。** 主论文 Fig. 7 已研究期限与 θ；CoCaR 已研究质量感知缓存；ALL26 已研究预测与资源比例。已排除的宽泛想法见 [相关工作](related-work.md)。这些来源没有为 H1 提供完成的新颖性证明。

**疑问。** 差异是否只是 ψ 的输入价值变化、天然不可行请求或某个固定 θ 未调优？

**实现影响 / 下一验证。** 对“模型 × 块”验证边际，固定其余机制；分别保存潜在付款、接纳、合格服务、费用和容量。同轨迹比较策略，保留所有固定 θ，并用独立开发数据选择参数。需要观察稳定机制差异后再考虑简单历史统计变体。

## D06：切换时机单独检验

**问题。** 在使用相同联合分布集合和阶段总时长时，关系变化的先后或相位是否影响留存？

**解释 / 假设 H2。** 实例状态有历史，切换时机可能使同样需求组成产生不同的创建和闲置过程；H2 也可能无效。

**证据。** CoCaR-OL、TeDiServe 与 SeqMoE 已研究动态负载或预测决策；具体设置见 [相关工作](related-work.md)。动态性本身不能作为新颖性依据。

**疑问。** 改时机是否同时改了阶段长度、热度或未声明的局部边际？

**实现影响 / 下一验证。** 将配对实验与时机实验分开；明确保证全局还是逐块不变量，避免过度声明。在线策略不得读未来阶段或测试最优参数。

**当前状态。** 只完成slot6/12的固定切换观察；尚未实现H2所需的顺序或相位对照。

## D07：允许负结果，按证据撤回主张

**问题。** 什么情况下应停止改进叙事？

**解释 / 决策。** 如果候选机制已有同义工作、效果仅来自测试调参/额外资源/未来信息，或只有某一随机种子支持，就撤回优势及新颖性主张。无差异或排名反转也应记录。

**证据。** 当前查新只是有界检查，主论文直接引用链尚未完整核定；理论缺项与实现解释仍存在。

**疑问。** 是假设被否定，还是环境没有触发额外实例生命周期？须先区分。

**实现影响 / 下一验证。** 提交可解释的手工例与失败例，冻结测试协议后保留逐种子结果；结论引用真实输出。首期不设预期提升百分比，不使用“首次”“SOTA”或“已证明竞争比”。

## D08：回应短时域限制，保留负结果

**问题。** 12片先导能否充分检验θ16？历史规则是否真的改变了可淘汰实例的行为？

**证据。** θ16超过先导时域；先导全部52条开发/测试场景的历史规则事件与θ2一致。不能用这批结果声称完整比较了长期保留，也不能声称历史规则优越。

**决策。** 保留先导原始数据，新增24片扩展；换用开发11–13、测试201–210，不用测试挑θ。扩展中θ16发生释放，历史规则仍在50/52条场景中与θ2一致，另两条没有形成稳定利润优势。固定θ的利润排序随配对改变，同时潜在付款、闲置和暖槽超额也变化。完整证据见[发现](findings.md)。

**当前结论 / 下一验证。** 首期完成可复查的机制与配对评估，不提出新保留算法。后续先检验严格物理资源下效应是否保留，并加强历史基线及定价敏感性检查，再与老师讨论研究问题。原文疑点和直接引用链查新仍待补齐。
