## 原文未明确处及本项目约定

1. **集合与模式。** 伪代码第6–7行的 AND/同时加入与 Eq.(31)/(32) 不一致，第15行可能丢失获胜分支。本项目按公式独立生成 typed mode，并按真正获胜 mode 更新。
2. **并列与数值零。** 相同得分时 existing 优先，再按节点和分辨率字符串排序；1e-12为绝对零容差。空候选直接拒绝。这些规则与未来无关，但由项目补充。
3. **物理实例映射。** slot 开始冻结 Cᵗ/nᵗ；同 slot 新接纳按节点/模型/档组成 ceil(x/L) 个新实例，后续 new 仍含 init。已有组先按 ID 填充未满实例；若 dual 选择产生溢出，分给负载最小实例并记录超额，不伪装成严格可执行服务。
4. **底座。** 每节点每模型每档一个 protected 常驻实例，θ只释放增量实例。预置和闲置均计入物理容量。是否逐节点常驻并非原文明确给出的操作。
5. **无线与定价。** 固定有效每请求上传速率，未模拟 OFDMA 等分或 SINR；ξ解释为$/秒（正文与实验单位不一致）。阶梯金额人为公开配置。这阻止了原论文金额/图表的精确复现。
6. **零/负 Cᵗ。** 已有保留导致 Cᵗ≤0 时，只关闭 new 分支，existing 仍可能被接纳。这是印刷式除零缺项的边界约定；事件 `new_disabled_nodes` 保存该情况。
7. **资源格点。** 输入容量和资源需为 `resource_unit` 的整数倍，容差内归一化并保存实际值；残余容量由整数格点计算。状态违规作为事件，NaN、乱序请求和重复 ID 则作为输入/程序错误终止。
8. **证明。** Eq.(21)/(34) 与 Eq.(41)/部分证明的 L 因子不一致。项目保留印刷更新，未自行修正理论，也不继承竞争比。

## 不使用未来信息的配置界

`Bounds.from_config` 用最大配置付款/最小实例资源作为 φ₁上界；用最小付款减最大推理费、最大路径费×最大数据量、最大上传费作为利润下界，再除最大资源作为 φ₂下界。要求该下界为正。它覆盖配置域，不是从测试样本估计的极值，也不是原文精确全时域常数。

Rmax取最大实例资源/最小资源格点；正残余至少一个格点。Nmax取1/L，覆盖非空已有组的 n≥1。a、b按原文定义由这些保守界计算。No_pre new-only 不使用 β/Nmax/b 分支；没有将 n=0 默默替换成1。

## 指标语义

`qualified`仅表示抽象分配满足**标称精度和模拟期限**，不是在严格容量和并发限制下完成真实推理的比例。它必须与物理容量违规、`warm_slot_violation_total`一起阅读。`concurrency_excess`是该实例在本请求之后的累计超额，不能逐请求求和；总缺口由槽末暖组超额汇总。

`new_branch_requests`是承担原式init延迟的请求数；`created_extra`是实际新实例数，两者因L分组不同。`cold_blocked_rejections`只是一项“暖可行、冷不可行”的拒绝标记，不证明拒绝都由冷启动造成。没有真实神经网络执行，也没有请求队列/实际批处理时间测量。
