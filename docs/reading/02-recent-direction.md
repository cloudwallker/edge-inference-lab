# 第二篇笔记：数字孪生中的重训与推理竞争

核查日期：2026-09-29。范围：问题、模型、在线算法结构和与首期项目的差异；仅作阅读对照，不声称已重实现。

**原始来源：** Xuan Ai、Weifa Liang、Caiyi Liu，*Joint Optimization of Model Retraining and Inference Services in DT-Assisted Edge Computing*，IEEE Transactions on Networking，34:1804–1819，2026。[作者正式 PDF](https://www.cs.cityu.edu.hk/~weliang/papers/ALL26.pdf)、[DOI](https://doi.org/10.1109/TON.2025.3632228)。页 1804 写首次发表 **2025-11-18**、current version **2026-01-08**；不是最近三个月发表的论文。下文为印刷页码。

## 1. 问题：更新模型为什么也会损害当前服务？

**解释。** 有限算力同时用于重训和推理：多做重训可能改善后续准确率，但会挤占当前推理资源；被重训的模型在该时隙不能接纳自身请求。

**证据。** §III-B、§IV，页 1806–1811；Eq. (28) 将重训与当槽对应模型的请求服务互斥。论文假设一次重训不超过一时隙。

**疑问。** 真实模型是否存在热更新、双副本或跨多槽重训？这些不应默认被此模型覆盖。

**实现影响。** 这与空闲实例保留是不同决策。首期不加入重训状态或双副本，也不将“加重训”直接写成创新。

## 2. 问题：这里的准确率从哪里来？

**解释。** 数据和模型的陈旧程度用 AoI 表示；F 虽名为 freshness，数值越大表示越陈旧。更新数据并重训会改变 F，再通过给定函数映射为准确率。

**证据。** §IV-A–B，页 1807，Eq. (1)–(5)；§IV-D 的延迟/效用模型，页 1808，Eq. (13)–(17)。请求延迟在 D 内完全满足；在 βD 内可有部分满意度，β>1。

**疑问。** AoI 到准确率的映射怎样对应真实数据漂移？允许部分超期服务的满意度，与严格期限达标如何比较？

**实现影响。** 本项目使用固定模型分辨率的标称精度和严格期限，不能直接借用本论文效用作为货币利润，也不能用主论文 θ 表示这里请求的最低精度 θk。

## 3. 问题：预测与多臂老虎机分别做什么？

**解释。** LSTM 从历史每模型请求数及接纳率递推未来窗口。MAB 的 arm 是“重训占用资源比例 δ”，不是模型或保留时间；选定比例后，再决定重训模型和接纳请求。

**证据。** §V-B，页 1811–1812，Algorithm 1；§V-C，页 1812–1813，Algorithm 2 将两阶段分配归约为广义指派问题 GAP；§V-D，页 1814，Algorithm 3 根据奖励更新比例的选择概率。

**疑问。** 接纳率受到当前策略影响，预测误差和选择反馈怎样改变后续资源分配？更换 LSTM 或 MAB 是否仍满足原文理论条件？

**实现影响。** “历史预测 + 自适应资源配置”已有明确先例。首期只记录机制对照，不引入训练器、MAB 或该文理论保证。

## 4. 问题：论文实际评估了什么？

**解释。** 论文用仿真比较资源比例决策及参数影响，而非把真实神经网络重训作为本项目可直接复用的运行流程。

**证据。** §VI-A–C，页 1816–1818；比较 OL_MAB、均匀选比例的 OL_Multi、OL_UCB、Greedy 与 Random，并扫描网络、模型、请求量等参数。Theorem 3，页 1814–1816，讨论期望累积 regret；它不等同主论文的竞争比。

**疑问。** 在已核对章节中，没有直接看到固定精度与期限各自边际、仅改变配对关系的受控实验；这只是有限阅读范围内的观察，不证明未有人研究。

**实现影响。** 不能跨论文直接比较分数，也不能沿用其 regret 上界。首期保留 CPU 模拟与配对检验，下一步先补查相关工作，而不是移植整个算法。

## 5. 问题：后续方向是不是现成创新？

**解释。** 作者结论已经列出其他预测机制、资源分配鲁棒性和保护更新数据隐私等后续方向。

**证据。** §VII，页 1818；与 [相关工作记录](../related-work.md) 中质量感知缓存、预测驱逐和期限调度交叉对照。

**疑问。** 一个更具体的假设，是否只是已有机制换了术语或工作负载？

**实现影响。** 不把“换预测器”“加强化学习”“考虑质量和期限”独立当成研究贡献。保留的问题是可证伪的配对效应；其新颖性与实验效果分别核验。
