# 一页研究摘要

**项目：** EdgeInferenceLab，普通CPU可运行的边缘AI推理调度学习项目；自有代码MIT许可。

**阅读入口：** 梁維發参与的[Zhang等，TMC2025](https://www.cs.cityu.edu.hk/~weliang/papers/ZLXJY25.pdf)，以及[重训与推理联合优化，ToN2026](https://www.cs.cityu.edu.hk/~weliang/papers/ALL26.pdf)。从第一篇的实例闲置保留、最低精度、期限与利润出发；第二篇只阅读比较，未移植其LSTM/MAB。

**具体疑问：** 同样到达轨迹与模型访问，保持精度、期限各自分布，仅改变它们的配对，是否改变实例保留的价值？这比“加预测”“做自适应缓存”更具体，但仍是未经新颖性证明的学习评估问题。

**已有工作约束：** CoCaR已研究精度子模型缓存/路由，TeDiServe研究质量和期限相关实例配置，SeqMoE研究预测驱逐；版本、评估设定和正式状态记录在[相关工作](related-work.md)。没有把邻近论文不同模型设定直接当作本项目创新证据。

**实现与证据：** 公开原式1–4、31/32、39–42与函数对应；合成配对校验、固定底座、逐事件费用/资源账本、开发与测试分开。完成12片先导和24片扩展，两阶段各10个测试种子；保存所有固定θ、开发选择、历史变体及解释/教学基线。原文缺项和模式冲突按公开解释处理，未宣称作者代码完整复现或竞争比。

**实际发现：** 延长保留的利润排序随配对改变，并增加闲置；历史规则几乎未形成差异。配对也改变潜在付款；算法的暖槽超额使接纳不能直接当严格可执行服务。手工8请求例无资源违规，清楚展示额外实例的创建—闲置—再次访问。[详细结果](findings.md)。

**希望讨论：** 在严格资源约束和更充分触发历史基线的环境中，配对效应是否仍成立？原算法候选、零预置和L因子应如何解释？下一步怎样缩小为有充分相关工作差异、能被普通CPU实验检验的问题？

这份摘要展示可检查材料，不替代本人理解或证明研究能力。建议按[学习路线](learning-guide.md)亲自复做手算和一组实验后再用于科研组讨论。
