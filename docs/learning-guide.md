# 四至六周的个人阅读与实验路线

项目提供可运行代码和证据入口；这些材料不能代替本人理解。建议把自己能解释和复做的内容作为申请科研组的学习记录。每周完成一个小问题，写自己的说明，并保留失败或不确定之处。

| 周次 | 阅读与动手 | 能向老师解释的证据 |
|---|---|---|
| 1 | 主论文§III、§V-A–C、§VI-A；查清标称精度、在线信息、primal/dual和θ | 不看代码手算暖/冷延迟、付款与三项费用，解释为何新建只有时延没有独立货币费 |
| 2 | 跑smoke；跟踪一份实例的创建、使用、闲置、释放 | 手算`retention-case`；用事件复算θ2/θ4结果，解释每个拒绝 |
| 3 | 对照Eq31/32/39–42与代码；理解原文歧义 | 手算α/β两次更新，解释slot冻结、ceil(x/L)、常驻floor和资源松弛 |
| 4 | 重跑主实验；观察配对、总潜在付款和策略差值 | 从相同轨迹解释一个差异及一个无差异；不能把模拟质量当真实测量 |
| 5，可选 | 阅读ALL26与相关近作；复核候选问题 | 写“已有工作覆盖什么、我的具体问题是什么、还缺哪项证据”，更新版本和状态 |
| 6，可选 | 设计一项范围小的后续验证，与老师讨论 | 先固定假设/参数/开发和测试分离，再实验；保留负结果，避免测试挑赢家 |

第一周先能回答：

1. 请求的最低精度与模型标称精度有什么区别？为什么本项目没有测真实预测准确率？
2. 原文的已有实例和new分支怎样满足不同的期限条件？
3. 为什么一次warm接纳后，new可能获胜，即使暖实例还有空位？
4. θ到底作用在哪一个实例？最后一份floor为什么不释放？
5. 净利润增加可能来自付款变化、资源松弛或留存机制中的哪一项？怎样区分？

后续学习记录可自己新增到`docs/reading/`，沿用“问题—解释—证据—疑问—实现影响”。记录能独立复做的推导、自己修改过的实验和结果；不要将自动生成文本或未验证理解改写成个人完成声明。

当前路线是[受控学习评估](experiments.md)。如果对偶算法暂时难以掌握，可以先读独立hard-cap贪心的机制，再对比原式；不能用该贪心的结果代替论文算法路径。查新未完成、机制不触发或结果无优势，都是需要解释的发现。
